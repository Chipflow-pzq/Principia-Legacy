# Implementation status and scope limits

This release distinguishes a runnable software package from a completed atlas or a validated alignment method. See BUILD_STATUS.md and RELEASE_REPORT.json for measured counts and outcomes.

| Contract | Delivered behavior | Remaining limitation |
|---|---|---|
| Local reader | Bundled React/TypeScript/Cytoscape/KaTeX; standard-library Python server; SQLite FTS5 and adjacency indexes | Loopback only; no hosted collaborative editor |
| Knowledge records | Contribution, Relation, Source and Review with stable IDs, immutable revisions, hashes and source anchors | Historical attribution and scientific truth still need specialist scrutiny |
| Typed relationships | Five layers, shared predicate registry, explicit warrants, symmetric edges, joint-premise groups | Mixed paths are not transitive proofs; no fabricated connectivity |
| Sixty topics | All assignments and open gaps visible; five explicitly pinned flagship endpoints | Contribution count target met; relationship target, nine precise endpoints and comprehensive ancestry remain incomplete |
| Idea families | Small editorial navigation groups preserve distinct source occurrences | Grouping is not equivalence, priority evidence or merged identity |
| Authoring | Bounded source acquisition; separate extraction/criticism; resumable provider jobs; redacted usage receipts | Explicit configured source passes, not autonomous depth-six historical reconstruction; successful admitted passes are reused, and corrections use explicit revision workflows |
| Corrections | Propose, impact, apply, source refresh comparison, exact-source machine recheck, human attestation import | A human attestation is not cryptographic identity verification |
| Living snapshots | Immutable release manifests; historical reading; readable additions and revision comparisons | Maintainers initiate updates; no background internet monitoring |
| Exports | Deterministic read-only briefs with selected relation endpoint/source closure, assumptions, limits and reviews | Bounded selected evidence, not all recursive ancestry; one full package, no selective subject archives |
| Normative arguments | Attributed and explicitly separate from empirical findings | No single moral objective or consensus policy is inferred |
| Research evaluation | 120 frozen synthetic cases and five conditions; actual responses, misses and unfavorable results retained | Character ceilings and reported tokens, not exact input-token matching; no independent expert gold labels; no demonstrated typed-atlas advantage |
| Human audit | Reproducible stratified 100-contribution/150-relation queue | No qualified human audit has occurred |
| Offline and security checks | Browser external-request blocking; outbound socket denial; read-only API; public-address-pinned source acquisition; safe asset paths and SQL; escaped text and untrusted-source fixtures | Tests are bounded checks, not a universal security guarantee |
| Portability | Launchers for macOS, Linux and Windows; three-platform CI configuration | Only macOS executed in this implementation session |

Remaining relationship and ancestry shortfalls are reported explicitly. Unsupported source assignments and relationships are rejected instead of being used to satisfy count targets. The next content release should resolve precise endpoints and source gaps, expand the explanatory checklists, and obtain independent domain review before increasing confidence claims.
