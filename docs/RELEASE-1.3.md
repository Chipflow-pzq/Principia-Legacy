# 1.3 local acceptance candidate

**Reader 1.3.1-rc.2 · atlas 1.3.1-exploratory · 17 October 2026.**

This update makes the distinction between a reproducible atlas and personal research clearer, expands the foundations collection, and rechecks the reasons connecting existing ideas. It is prepared for local acceptance; it has not been deployed or pushed to GitHub.

## Reading and navigation

- One Explore workspace offers **Browse the atlas** and **Trace a discovery**. Search results, topic context and unfinished questions survive mode changes.
- Ordinary navigation opens `/#page=explore`. Obsolete preview parameters are removed. Historical atlas links retain their snapshot; Settings identifies the application version separately.
- Search prioritizes direct title matches. Inspectors link to containing topics and preserve navigation through other search results.
- Locally bundled mathematics, stable graph positions, distinct arrow colors and patterns, accessible lists, keyboard navigation and narrow-screen layouts remain available offline.
- Topic coverage identifies isolated insights instead of implying that every idea has a warranted connection.

## Content and corrections

The collection now contains **2,880 visible insights, 1,920 relationships and 182 populated topics**. Thirty additional foundation topics cover six assignments in each subject, including probability, linear algebra, electromagnetism, algorithms, population genetics and economic measurement.

All 2,233 relationships visible in the preceding collection were rechecked. This pass withheld 463 and repaired 23. Additional editorial corrections address mathematical scope, reduction direction, independent discovery, scientific limitations and incorrect source locators. Changed content invalidates dependent interpretations; fresh checks determine which can return. Older snapshots remain reproducible.

The net expansion is 213 insights. A smaller relationship count reflects rejected warrants rather than an attempt to draw a more connected-looking graph. The subject coverage targets remain unmet, two registered topics are still empty, and qualified human auditing has not been performed.

## Personal exploration

Users configure their own SiliconFlow account in global Settings. The browser retrieves sources, selects insights, proposes typed connections and checks them separately. Bounded progress, partial-result inspection, explicit save/download and resumable unfinished review make the workflow inspectable.

Provider handling now bounds response content separately from streaming metadata, preserves completed checks, handles supported output-format differences, detects input/template copying, and limits repair attempts. Four focused literature searches complement direct searches for foundations and mechanisms. Smaller node-check batches assess scope and duplicate ideas. No model is silently substituted and missing usage is not treated as free.

The final six-query Flash run completed all requests in 106–156 seconds; four met the graph-structure criterion. Lithography and AlphaFold did not, and primary-agent inspection found additional scope defects in some structurally connected maps. Autonomous tracing therefore remains an experimental feature and is not certified for unattended public research.

Generated maps remain **unverified personal drafts**. A successful request or model check does not guarantee an adequate scientific explanation. Missing links stay visible. The [acceptance report](../reports/product-readiness-1.3.md) records current live outcomes, earlier failures, performance, coverage and remaining limitations separately.
